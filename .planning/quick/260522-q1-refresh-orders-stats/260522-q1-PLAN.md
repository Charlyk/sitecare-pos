# Quick Task 260522-q1: Refresh Orders & Stats

## Goal

Wire the existing Reîmprospătează / Refresh button in `OrdersScreen` to invalidate the `['orders']` and `['stats']` TanStack Query caches, triggering a background refetch.

## Task 1: Wire refresh button in screen-orders.jsx

**File:** `src/screen-orders.jsx`

**Action:**
1. Import `useQueryClient` from `@tanstack/react-query`
2. Call `useQueryClient()` inside `OrdersScreen`
3. Add `onClick` to the Reîmprospătează button: invalidate `['orders']` and `['stats']` query keys

**Verify:** Clicking Refresh triggers network requests for both orders and stats.
