# Quick Task 260506-q1: Add logout option to sidebar user chip

## Goal
When the user clicks the user chip at the bottom of the sidebar, show a small popup menu with a "Log out" option that triggers `signOut()`.

## Tasks

### Task 1: Add i18n keys for logout
- **Files:** `src/i18n.jsx`
- **Action:** Add `logout: 'Deconectare'` (RO) and `logout: 'Log out'` (EN)

### Task 2: Add logout and chevUp icons
- **Files:** `src/icons.jsx`
- **Action:** Add `chevUp` and `logout` icon paths

### Task 3: Wire logout dropdown in Shell
- **Files:** `src/shell.jsx`
- **Action:**
  - Import `useRef` and `useAuth`
  - Read `authUser` from store for real display name + initials
  - Add `userMenuOpen` state + outside-click dismissal via `useEffect`
  - Wrap user chip in a relative container with the dropdown rendered above it
  - Dropdown: single "Log out" button calling `signOut()`
  - Show chevron (up/down) indicator when sidebar is expanded
