<objective>
Route the one error path that bypasses TanStack's onError — the SSE stream's onopen non-2xx —
into the same central handler, and STOP retrying on a branch-access 403 so the library does not
loop forever with blind exponential backoff against an inaccessible branch (D-08, SC2).

Purpose: SC2 explicitly names a stream reconnect as a recovery trigger; leaving the stream to
retry-storm a revoked branch is both a UX gap and a self-inflicted DoS on the API.
Output: an onopen branch-403 short-circuit that recovers via handleBranchError and returns
without throwing, with non-branch errors' retry behavior untouched.
</objective>
