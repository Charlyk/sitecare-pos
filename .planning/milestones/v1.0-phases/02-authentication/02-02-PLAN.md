## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user input→component state | Email and password are typed by the user into controlled inputs |
| component→onSubmit prop | email, pass, remember values passed up to auth layer |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Tampering | Email input | mitigate | Client-side regex `/^[^\s@]+@[^\s@]+\.[^\s@]+$/` guards before onSubmit is called; server rejects invalid credentials anyway |
| T-02-05 | Information Disclosure | Password field | mitigate | `type="password"` by default; showPass toggle uses `type="text"` only when user explicitly requests it |
| T-02-06 | Denial of Service | Rapid submit clicks | mitigate | `disabled={!canSubmit}` and `busy` flag prevent double-submit; button disabled during in-flight request |
</threat_model>
