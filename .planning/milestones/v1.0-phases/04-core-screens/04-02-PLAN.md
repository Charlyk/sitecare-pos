## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SSE onmessage → Audio.play() | Live order event triggers audio playback — bypass is soundMuted flag |
| User input (prep time) → updateStatus.mutate | Prep time integer flows from dialog input to API body |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-02-01 | Tampering | AcceptDialog estimatedMinutes | mitigate | Value validated in UI (disabled when <= 0); API also validates range 1-480 |
| T-04-02-02 | Denial of Service | Audio.play() on every SSE event | mitigate | snapshotDone flag prevents burst-play on connect; .catch(() => {}) prevents unhandled rejections |
| T-04-02-03 | Spoofing | statusToSDK fallback (.toUpperCase()) | accept | Fallback only activates for unknown states; API validates enum on server side |
| T-04-02-04 | Information Disclosure | Token in useSSE dependency array | accept | Token is already in memory (from AuthProvider); not new exposure |
</threat_model>
