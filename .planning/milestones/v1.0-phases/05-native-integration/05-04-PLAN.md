  <how-to-verify>
    Run the app: `npm run tauri dev`

    **Check 1 — Printer Setup UI (PRNT-01)**
    1. Navigate to the Printer screen via the sidebar
    2. Confirm: eyebrow reads "thermal printer" / "imprimantă termică", heading reads "Printers" / "Imprimante", subtitle is visible
    3. Confirm: port dropdown is present and populated (or shows "No ports found" if no printer connected)
    4. Confirm: paper width toggle shows 58mm / 80mm buttons; clicking each changes the active state (sage border + tint)
    5. Confirm: printer name field is present with placeholder
    6. Confirm: auto-print toggle is visible but greyed-out (cannot click it)
    7. Confirm: receipt preview panel on the right shows ThermalTicket component

    **Check 2 — Save + Connection Test (PRNT-01, D-11)**
    With a USB thermal printer connected:
    1. Select the correct COM port from the dropdown
    2. Click Save
    3. Confirm: button shows "Saving…" / "Se salvează…" while pending
    4. On success: confirm green chip "Printer connected" / "Imprimantă conectată" appears
    5. On success: confirm Test Print button becomes active (no longer greyed-out)
    With wrong/no printer:
    6. Select a non-existent port, click Save
    7. Confirm: red chip "Connection failed" / "Conexiune eșuată" appears with error detail text
    8. Confirm: Test Print button remains disabled

    **Check 3 — Test Print (PRNT-02, D-12)**
    After a successful Save:
    1. Click "Test Print" / "Print de test"
    2. Confirm: button shows "Printing…" / "Se printează…" while pending
    3. Confirm: a test slip prints from the printer — it shows restaurant name, "TEST PRINT", a ruler line, no order data, ends with paper cut
    4. Confirm: success toast "Ticket printed" / "Bon printat" appears (clicks to dismiss)

    **Check 4 — Order Receipt Print: customer (PRNT-03, ACT-04)**
    1. Navigate to an existing order and open its detail screen
    2. Click "Print customer" / "Print client" button
    3. Confirm: receipt prints with:
       - Restaurant name centered/bold at top
       - Order number (#NN) and time
       - Line items with quantities and prices
       - Totals (Subtotal, TVA, Total RON)
       - Footer: "Multumim! / Thank you!" and "sitecare.ro"
       - Paper cut at end
    4. Confirm: success toast "Ticket printed" / "Bon printat" appears

    **Check 5 — Order Receipt Print: kitchen (PRNT-03, ACT-04)**
    1. From the same order detail, click "Print kitchen" / "Print bucătărie"
    2. Confirm: kitchen ticket prints with:
       - Restaurant name at top
       - "*** BON BUCATARIE ***" banner (inverted/prominent)
       - Line items with quantities — NO prices shown
       - NO totals section
       - Footer and paper cut
    3. Confirm: success toast appears

    **Check 6 — No printer configured (ACT-04)**
    1. If possible, clear the printer config (or test on a machine without a configured printer)
    2. Click any print button on Order Detail
    3. Confirm: error toast "Printer not configured" / "Imprimanta nu este configurată" appears
    4. Confirm: no invoke call attempted (no Rust error — just the JS guard)

    **Check 7 — Offline state**
    1. Enable offline mode (disconnect network or use browser devtools)
    2. Confirm: Save button on Printer Setup is disabled (greyed-out)
    3. Confirm: Test Print button on Printer Setup is disabled
    4. Confirm: Print buttons on Order Detail are disabled with `.btn-disabled-offline` class

    **Check 8 — Language switch**
    1. Switch to Romanian in Settings
    2. Return to Printer Setup — confirm all labels are in Romanian
    3. Switch back to English — confirm labels return to English
