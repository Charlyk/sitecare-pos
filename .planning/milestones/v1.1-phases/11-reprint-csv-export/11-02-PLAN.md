    - Escaping: a value containing comma, double-quote, or newline is wrapped in double-quotes with embedded quotes doubled; a plain value is emitted unquoted (D-12).
    - Formula injection (T-11): a value whose first character is `=`, `+`, `-`, `@`, tab, or carriage-return is prefixed with a single leading apostrophe BEFORE the RFC-4180 quote step, so a customer name like `=1+1` cannot execute as a spreadsheet formula.
    - Partial rows: a null/undefined field (e.g. dine-in order with no deliveryFee, walk-in with null customer.phone) serializes as `""` (empty field), never `null`/`undefined`/`N/A`, and never a dropped position — every row has exactly 13 fields (Pitfall 5).
    - Zero/one/many: 0 orders → header-only string (still BOM-prefixed); 1 and many rows share identical structure.
    - Large export: a synthetic set of ~2000 orders (a full-year worst case under MAX_RANGE_DAYS=366) builds in < 1000ms (generous threshold to avoid CI flakiness while catching an accidental O(n^2) regression). Name the test so `-t "large export"` selects it.
