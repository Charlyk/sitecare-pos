## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| date-input `.value` → range query | Two raw `'YYYY-MM-DD'` strings from a native input cross into the values that parameterize an unpaginated, unvirtualized API fetch. `validateCustomRange` is the authoritative gate; the native `min`/`max` (09-05) is only an affordance. |
| resolved range → rendered period label | `formatDateRange`'s output is what tells staff which accounting period they are reading. A wrong rendering is a false claim about money, not a cosmetic bug. |
