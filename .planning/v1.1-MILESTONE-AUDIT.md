## 4. Tech Debt (ranked)

1. **[CRITICAL] CR-01 — fallback `total` omits `tax`** (`src/data.jsx:214-216`, Phase 10 review, **still OPEN**). `normalizeOrder`'s fallback total calculation (used when the SDK doesn't return `order.total` directly) omits tax — a financial-correctness bug. Pre-existing since v1.0 (2026-05-06). Does not block any HIST requirement, but ships incorrect totals on the fallback path. The project's own review flagged it and no fix commit followed. **Decide: fix in a short follow-up, or explicitly log to a tracked backlog item before v1.1 ships.**

2. **[WARNING] Return-from-detail state continuity** (cross-phase 07/08/09/10). Period + filters reset when returning from the read-only detail because `HistoryScreen` is unmounted. Filter reset is an accepted v1.1 deferral; period reset partially conflicts with Phase 8 SC4's literal wording. Fix (if wanted): lift `selectedPeriod`/`statusFilter`/`typeFilter`/`query` to the store or a parent that outlives the route switch.

3. **[WARNING] HIST-06 traceability gap** (Phase 7). Functionally delivered and verified, but the requirement tag is orphaned from all verification bookkeeping (and Phase 7 VERIFICATION.md:101 mis-states its scope). Fix: add HIST-06 to a phase-7 SUMMARY `requirements-completed` and correct the VERIFICATION note — a doc-only edit.

4. **[WARNING] WR-01 — Custom pill popover re-click** (Phase 9, `src/screen-history.jsx` outside-click ref). Re-clicking the open Custom pill doesn't close the popover (mousedown/click race). Fix: widen the outside-click ref to wrap toggle + panel, per `shell.jsx`'s precedent.

5. **[WARNING] G-07-1 — Rust dead_code warning** (`src-tauri/src/lib.rs:59`). `PrintOrderData.table` field never read; user asked for it to be fixed.

6. **[INFO] 3 pre-existing unrelated test failures** (from v1.0, Phase 6): `build-pipeline.test.js` BILD-04 (updater-artifacts config) + `offline-buttons.test.jsx` ×2 (missing `QueryClientProvider` wrapper). Documented in every phase's `deferred-items.md`; the full suite is otherwise green (481/484 at Phase 11 tip).
