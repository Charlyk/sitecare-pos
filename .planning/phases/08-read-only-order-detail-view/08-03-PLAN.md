<objective>
Make the read-only detail view tell the truth about a finished order: replace the meaningless
elapsed-since-now counter with the actual duration derived from event timestamps, and replace the
live-lifecycle status chip with the same derived status the History row shows.

Purpose: both are correctness fixes for an archive view rendering with live-order logic.
`elapsedMinutes(order.placedAt)` on an order finished three weeks ago renders "30240 min" — a number
about now, not about the order. And `stateMeta` has no `cancelled` or `refunded` entry at all, so a
cancelled historical order currently falls through to `map.new` and renders a terracotta **New** chip
directly contradicting the **Canceled** chip staff clicked to get here.

Output: a header meta line that reads correctly for archived orders, and a status chip that agrees with
the History list by construction.
</objective>
