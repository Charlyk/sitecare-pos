<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| AuthProvider→context consumers | Raw session token string flows from AuthProvider into React context; any component inside the provider tree can access it |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-3-01 | Information Disclosure | AuthContext token field | accept | Token is a session credential in a React context accessible only to components inside the provider tree (the whole app). Tauri's renderer is a single process; there is no cross-origin access. Token is never serialized to localStorage or sent to a non-API URL. The existing tokenRef already holds this value — adding it to context does not increase exposure. |
| T-3-02 | Spoofing | useSSE SSE connection | mitigate | Token placed in Authorization header only (Bearer scheme). Never placed in URL query params. @microsoft/fetch-event-source supports headers natively. The `if (!token) return early` guard in useSSE (Plan 03) prevents SSE from connecting before auth completes. |
</threat_model>
