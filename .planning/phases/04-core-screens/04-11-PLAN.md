<objective>
Close 3 UAT-diagnosed regressions from the Phase 4 acceptance run.

Gap 1 (major): SSE stream suspends when the app window is backgrounded because
`openWhenHidden: true` is missing from the `fetchEventSource` call in `use-sse.js`.
The fix is a single option addition plus a new test asserting the option is passed.

Gap 2 (cosmetic): Ring Up toast shows `##0001` because the `onSuccess` callback in
`screen-pos.jsx` prepends a literal `#` to `result.data?.dailyNumber`, but the API
field `dailyOrderNumber` already carries the `#` prefix. Fix the field name and
remove the extra prefix; update the existing success-toast test to assert the
correct single-prefix format.

Gap 3 (minor): Density toggle has no visible effect because the only CSS rule
(`.density-compact .card { padding-block: 0 }`) sets padding to zero (too
aggressive) and misses elements that set padding via inline `style` on order rows
and KDS cards. Fix: replace the broken rule with sane reduced values, add
`order-row` and `kds-card-body` class-based density rules, then move inline
padding on those elements to use those classes so the cascade can reach them.

Purpose: All 3 gaps are required for the UAT to reach 20/20 pass.
Output: Five modified source files plus updated tests; no new files.
</objective>
