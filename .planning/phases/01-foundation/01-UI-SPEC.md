# Phase 1 — UI Design Contract

> Visual and interaction contract for the Foundation phase. This is a MIGRATION phase, not a design-from-scratch phase. The design system is LOCKED — it exists in the prototype and must be preserved exactly during implementation. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — prototype CSS migrated verbatim |
| Preset | not applicable |
| Component library | none — hand-authored CSS classes from prototype |
| Icon library | Inline SVG via `Icon` component (`src/icons.jsx`); Lucide-style paths, 1.5–1.75px stroke, rounded caps |
| Font (primary) | Outfit — weights 300/400/500/600/700/800/900; Bold (700) and Black (900) bundled as `.ttf`; other weights via Google Fonts |
| Font (accent) | Caveat — weights 400/600/700 via Google Fonts; used for brand sub-label, eyebrow, greeting |

**Source files (both imported once in `main.jsx`, never in components):**
- `src/colors_and_type.css` — all `--sc-*` custom properties (migrated from `assets/colors_and_type.css`, path unchanged in relation to fonts)
- `src/styles.css` — monolithic component and layout CSS (verbatim copy of `index.html` `<style>` block)

**CSS rule:** no per-component CSS files, no Tailwind, no CSS-in-JS. Inline `style` objects for dynamic/conditional values; class names for static structural rules.

## Spacing Scale

Declared values. All spacing values in the prototype use direct `px` literals in inline styles — these map to the following scale.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, nav item dot indicator, tl-dot gap |
| sm | 8px | Button internal gap, brand gap, topbar gap |
| md | 16px | Content padding (content-pad starts at 24px), sidebar padding-inline, button padding |
| lg | 24px | `content-pad` padding, topbar padding-inline |
| xl | 32px | Section breaks inside screens |
| 2xl | 48px | Not explicitly used in Phase 1 scaffold |
| 3xl | 64px | Not explicitly used in Phase 1 scaffold |

> MIGRATION EXEMPTION: The exception values in this table are prototype-verbatim pixel values preserved for pixel-perfect fidelity. They must not be rounded or adjusted. No new non-multiple-of-4 spacing values may be introduced in implementation.

Exceptions:
- Sidebar padding: 18px top, 14px inline, 14px bottom (prototype values — preserved verbatim)
- Topbar height: 64px (prototype `.topbar { height: 64px }`)
- Navbar height token: `--sc-navbar-height: 68px` (defined in tokens; topbar renders at 64px in the prototype — preserve both)
- Nav item padding: 9px 10px (preserve verbatim)
- Nav group label padding: 14px 10px 6px (preserve verbatim)
- Touch targets: nav items and icon buttons meet 38px minimum height (`.icon-btn` is 38×38px, `.nav-item` is ~36px — no change needed for desktop)
- Sidebar width: 240px (`.app-body { grid-template-columns: 240px 1fr }`)

## Color

| Role | HSL Value | Hex (approx) | Usage |
|------|-----------|--------------|-------|
| Dominant (60%) | `hsl(40 60% 97%)` | #fdf9f0 | Page background (`--sc-background`); sidebar gradient base |
| Secondary (30%) | `hsl(40 30% 94%)` | #f5f0e8 | Cards (`hsl(0 0% 100%)` = white), sidebar gradient, topbar overlay (`rgba(255,255,255,0.6)`), muted surfaces (`--sc-secondary`, `--sc-muted`) |
| Accent / Primary (10%) | `hsl(120 14% 49%)` | #6b8c6b | Nav active item, `.btn-primary`, `.btn-primary:hover` at `hsl(120 14% 42%)`, role pill active, `.chip-sage` tint, nav count badge tint, toast icon bg, brand logo bg, focus ring |
| Terracotta | `hsl(0 53% 58%)` | #c85a5a | Handwriting/eyebrow text, `.btn-terracotta`, new-order pulse animation, user avatar bg, nav dot indicator, notification bubble |
| Destructive | `hsl(0 84.2% 60.2%)` | #f04040 | Destructive actions only (`--sc-destructive`); cancel/delete confirmations |
| Border | `hsl(120 10% 88%)` | #dce8dc | All borders: cards, sidebar, topbar, inputs, icon-btn, buttons |
| Card surface | `hsl(0 0% 100%)` | #ffffff | Card backgrounds, btn-secondary, search box, icon-btn |
| Foreground | `hsl(120 8% 15%)` | #242b24 | Primary text (`--sc-foreground`) |
| Muted foreground | `hsl(120 5% 46%)` | #6e786e | Secondary text, nav labels, search placeholder (`--sc-muted-foreground`) |

**Accent system (runtime mutation):**
On `document.documentElement`, `--sc-primary`, `--sc-primary-hover`, and `--sc-primary-soft` are mutated when `accent` state changes. Four themes:
- `sage` (default): primary = `hsl(120 14% 49%)`, hover = `hsl(120 14% 42%)`, soft = `hsl(120 14% 49% / 0.10)`
- `indigo`: primary = `hsl(234 60% 55%)`, hover = `hsl(234 60% 48%)`, soft = `hsl(234 60% 55% / 0.10)`
- `terracotta`: primary = `hsl(0 53% 58%)`, hover = `hsl(0 53% 52%)`, soft = `hsl(0 53% 58% / 0.10)`
- `charcoal`: primary = `hsl(220 9% 30%)`, hover = `hsl(220 9% 24%)`, soft = `hsl(220 9% 30% / 0.10)`

Accent is reserved for: active nav item background, primary action buttons, role pill active state, focus ring, brand logo background, chip-sage tint, nav count badge background, toast icon tile, `.active` state borders on order cards.

**Primary focal point:** The active nav item in the sidebar communicates current context at a glance; the order card list is the primary content anchor on the Orders screen. All `.icon-btn` elements receive `aria-label` attributes matching their action noun (e.g., `aria-label="Search"`, `aria-label="Notifications"`).

## Interaction Contracts

### Window Chrome
- `decorations: true` (D-01) — native OS title bar. No custom titlebar component. `lib/macos-window.jsx` is archived, not migrated.
- Default window size: 1440×900 (matches prototype's fixed frame). `@tauri-apps/plugin-window-state` may persist size/position; Claude decides initial size.

### Screen Router
- No router library. Screen switching is conditional JSX rendering gated on `screen` string in Zustand store.
- Valid screen keys: `'orders'`, `'kitchen'`, `'pos'`, `'detail'`, `'menu'`, `'printer'`, `'settings'`
- `detail` screen requires companion `selectedOrder` state to be set.

### Unimplemented Screens
- Screens not yet wired to live data must be **visually greyed out** (opacity reduction or muted color), **visible** in nav, and **not clickable** (pointer-events: none or disabled state). Do NOT hide them.

### Accent Theming
- `useEffect` in `app.jsx` watches `accent` state and mutates `--sc-primary`, `--sc-primary-hover`, `--sc-primary-soft` on `document.documentElement`.
- Default accent on first run: `'sage'`.

### Animation
- All transitions: `150ms` (button hover, nav item hover, role pill) or `200ms` (`--sc-duration`) for general transitions.
- Animation easing: `cubic-bezier(0.4, 0, 0.2, 1)` (`--sc-easing`).
- Toast entry: `slideIn 250ms cubic-bezier(0.2, 0.8, 0.2, 1)`.
- New order pulse: `pulseRing 1.6s infinite`.

### Density
- `density` state: `'balanced'` (default) or `'dense'`.
- Dense mode applies `.density-compact` class to root, which reduces card vertical padding.
- Persisted via `@tauri-apps/plugin-store`.

### i18n
- `lang` state: `'ro'` (default) or `'en'`.
- All user-visible strings go through `useT(lang)` hook returning `t(key)`.
- Inline ternaries (`lang === 'ro' ? ... : ...`) are acceptable for short strings already in the prototype; new strings must use `t()`.
- Romanian is the canonical language.

## Zustand Store Shape (Phase 1)

The Zustand store is the production replacement for the prototype's `React.useState` in `App`. Claude has discretion over exact slice structure (per CONTEXT.md).

Required state keys for Phase 1 (maps to `sc_*` localStorage keys from prototype):

| Key | Type | Default | Persistence |
|-----|------|---------|-------------|
| `screen` | `'orders' \| 'kitchen' \| 'pos' \| 'detail' \| 'menu' \| 'printer' \| 'settings'` | `'orders'` | plugin-store (`sc_screen`) |
| `role` | `'cashier' \| 'kitchen'` | `'cashier'` | plugin-store (`sc_role`) |
| `lang` | `'ro' \| 'en'` | `'ro'` | plugin-store (`sc_lang`) |
| `accent` | `'sage' \| 'indigo' \| 'terracotta' \| 'charcoal'` | `'sage'` | plugin-store (`sc_accent`) |
| `density` | `'balanced' \| 'dense'` | `'balanced'` | plugin-store (`sc_density`) |
| `sidebarCollapsed` | boolean | `false` | plugin-store (`sc_sidebar_collapsed`) |
| `selectedOrder` | object \| null | `null` | NOT persisted (session only) |
| `toasts` | array | `[]` | NOT persisted (session only) |
| `acceptDialog` | object \| null | `null` | NOT persisted (session only) |

Persistence: `@tauri-apps/plugin-store` writes to a named store file (e.g., `preferences.json`). All six persisted keys load from store on app init; defaults apply when key is missing.
